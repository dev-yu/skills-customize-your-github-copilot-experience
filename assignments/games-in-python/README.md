
# 📘 Assignment: Hangman Game Challenge

## 🎯 Objective

Build a Hangman game in which a player guesses a hidden word before running out of attempts. Practice using strings, loops, conditionals, user input, and random selection.

## 📝 Tasks

### 🛠️ Task 1: Build the Hangman Game

#### Description
Write a program that chooses a word from a predefined list and lets the player guess it one letter at a time.

#### Requirements
Completed program should:

- Randomly select a word from a predefined list
- Accept letter guesses and show correctly guessed letters while hiding the rest (for example, `_ _ _`)
- Track and display the number of incorrect guesses remaining
- End the game when the word is guessed or no attempts remain
- Display a clear win or lose message

### 🛠️ Task 2: Handle and Test Guesses

#### Description
Make the guessing experience clear and test the game with both valid and repeated or invalid input.

#### Requirements
Completed program should:

- Tell the player when a guess is not a single letter
- Tell the player when they repeat a guess without counting it as a new incorrect guess
- Keep accepting guesses until the player wins or runs out of attempts
- Verify that the game handles correct guesses, incorrect guesses, repeated guesses, a win, and a loss
